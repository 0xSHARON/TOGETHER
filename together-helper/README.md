# TOGETHER HELPER

Multipurpose Discord Bot and Management Dashboard for the TOGETHER community.

## Features
- **Moderation**: Timeouts, kicks, bans, warnings, message purging, lock/unlock, slowmode.
- **Support & Tickets**: Interactive tickets, transcripts, direct messaging.
- **Giveaways**: Button entries, automatic winner rolling and notifications.
- **Economy & Levelling**: XP system, levels, leaderboards, and rewards.
- **Automod & Protection**: Anti-spam, link filters, raid protection, and auto-role.
- **Mission Control Dashboard**: Modern React + Vite dashboard at https://help.together.dpdns.org/
